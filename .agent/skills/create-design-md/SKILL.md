# Create DESIGN.md

Create a `DESIGN.md` for one product or coherent website. Record the design language that governs it, not every value that happens to exist.

## Guidelines
- Extract design tokens, color palette, typography hierarchy, surfaces, and spacing.
- Document glassmorphism, border radii, shadows, and motion principles.
- Use structured YAML frontmatter for programmatic tokens and clear markdown documentation.
