# Frontend Design

This edition derives from Anthropic's frontend-design Skill at commit 2235be7c60b551f5de82ade908fd3816455afcda.

## Design loop

Frame the job, write a thesis, run the subject-specific swap test, build from the thesis, and verify delivery through a rendered critique. Use real content and preserve product behavior in reshape work.

The natural package remains SKILL.md plus LICENSE.txt. The edition changes the instruction file only; no screenshots or rendered proof are included in this release edition.

## Core Design Principles
- **Distinctive Typography**: Curated pairings with crisp scales and high readability.
- **Intentional Color Systems**: Strong dominant tone, atmospheric dark modes, nuanced secondary hues, and high-contrast accents.
- **Spatial Rhythm**: Cohesive spacing grid, subtle glassmorphism, depth through z-index layering and soft shadows.
- **Motion Polish**: Meaningful micro-interactions, smooth hover states, responsive transitions, and fluid page flows.
