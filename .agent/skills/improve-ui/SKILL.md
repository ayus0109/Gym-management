# Improve UI

Audit one coherent product surface against the system that actually governs it. Preserve the product's identity, reuse existing owners, and prefer no finding to an unsupported one.

## 1. Select the surface
Trace the rendered path through compositions, shared components, variants, resolved tokens, and styles.

## 2. Reconstruct the local system
Inspect tokens, variables, themes, primitives, variants, and compositions relevant to the traced path.

## 3. High Leverage UI Refinements
- Hierarchy, typography scales, contrast ratios, and density.
- Card elevations, border strokes, and backdrop blur consistency.
- Responsive breakpoints and layout stability.
- State indicators: active, hover, focused, disabled, and loading skeletons.
